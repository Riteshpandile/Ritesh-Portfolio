# Ritesh Pandile — Flutter & Mobile App Developer Portfolio

A modern, high-performance, interactive portfolio showcasing production Flutter applications, state management architectures, real-time services, and mobile engineering excellence.

🌐 **Live Demo:** [riteshpandile.dev](https://github.com/Riteshpandile/Ritesh-Portfolio)

---

## ⚡ Key Highlights & Features

- **Interactive macOS-Style Dart Terminal**: Interactive Dart code card showcasing real-world Flutter architecture patterns.
- **3D 360° Profile Stage**: Interactive profile card flipping dynamically to reveal Flutter engineering credentials.
- **Continuous Ecosystem Stream**: Infinite dual-row marquee container featuring 21+ production tools, libraries, and frameworks across Mobile, State Architecture, Cloud/Firebase, and Store DevOps.
- **Architecture Flow Interactive Stepper**: Step-by-step interactive walkthrough of reactive state, caching, network interceptors, and local offline persistence.
- **Production Projects Bento Showcase**: Detailed case studies covering real-world deliverables (ERP systems, AI chat interfaces, real-time WebRTC calling, and IoT integrations).
- **Dual Theme Support**: Handcrafted curated HSL palettes for both Dark Mode and Light Mode with micro-interactions and neo-morphic glassmorphic depth.

---

## 🛠️ Tech Stack

- **Framework & Core**: [React](https://react.dev/), [Vite](https://vitejs.dev/)
- **Styling**: Handcrafted Vanilla CSS Design System (Glassmorphism, Neo-morphic cards, HSL color tokens)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Deployment**: GitHub Pages / Vercel / Netlify

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/Riteshpandile/Ritesh-Portfolio.git

# Navigate to project directory
cd Ritesh-Portfolio

# Install dependencies
npm install

# Start local development server
npm run dev
```

### Production Build

```bash
# Build optimized bundle
npm run build

# Preview production build locally
npm run preview
```
